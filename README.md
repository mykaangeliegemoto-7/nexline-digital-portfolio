## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example, `nexline-digital-portfolio`).
2. Upload the **contents** of this folder to the repository's root. Keep `index.html`, `.nojekyll`, `projects/`, and all nested project assets together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your public URL will appear in the Pages settings.
